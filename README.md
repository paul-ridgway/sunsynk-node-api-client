# Sunsynk/PowerView AP Client

An API Client for Sunsynk/PowerView using https://pv.inteless.com

Demo/example usage: [sundial-cli](https://github.com/paul-ridgway/sundial-cli)

## Publishing to npm

Releases use GitHub Actions trusted publishing (OIDC). If `npm publish` fails with **E404**, see [docs/npm-trusted-publishing.md](docs/npm-trusted-publishing.md).
